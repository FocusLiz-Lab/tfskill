# The Futur · 客户需求访谈方法说明

## 适用问题

- 需求模糊
- 客户沟通
- 项目简报

## 核心原则

- 需求发现优先于展示解决方案
- 区分症状和业务问题

## 标准步骤

1. 追问当前情况与变化目标
2. 核对决策者和利益相关者
3. 确定成功衡量与约束
4. 复述并确认项目问题

## 应交付的结果

- 访谈提纲
- 问题定义
- 项目简报
