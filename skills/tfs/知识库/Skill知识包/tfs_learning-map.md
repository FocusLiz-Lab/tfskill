# The Futur · 学习地图方法说明

## 适用问题

- 学习顺序
- 从哪里开始
- 概念解释
- 知识库怎么学

## 核心原则

- 以创意专业服务与客户合作的具体能力为学习目标，不按文稿数量安排任务
- 概念解释只解释当前概念，不自动扩展成完整课程
- 阅读推荐必须关联实际来源标题和URL，证据不足时标记缺口

## 标准步骤

1. 识别目标、基础、每周可投入时间，已有上下文足够则不重复询问
2. 按当前缺口选择学习顺序，参考能力链：创意服务定位 → 报价与价值沟通 → 客户需求访谈 → 提案与异议处理 → 项目范围与客户关系
3. 检索本地来源目录，列出每阶段2至4份实际存在的资料及阅读理由
4. 安排一个可观察的练习成果，写出自检标准和进入下一阶段的条件

## 应交付的结果

- 能力地图与当前起点
- 分阶段阅读路径及真实来源
- 练习成果与检验标准
